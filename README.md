# Orbit-Wallet

A full stack cryptocurrency dashboard designed with user experience at top of mind. 
This app combines clean design, real-time data, and intuitive workflows so users can explore the crypto world without the usual clutter.

Users are able to create an account, login, and build their dashboard as they like by pinning their favorite coins and repositioning them.
Coin price data is updated asynchronously. 

<a href = "https://orbit-wallet.herokuapp.com/"> Deployment </a>

## Technologies
- React.JS
- MongoDB
- Express
- Node.JS
- CoinGecko API
